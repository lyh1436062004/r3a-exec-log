+# Jev 能否用于 A2 / R3a：可行性判断与最小验证方案
+
+称呼：陆含
+资料核对：2026-10-07 至 2026-10-08（Asia/Shanghai）
+任务类型：资料研究与方案评估；本轮未接入 Jev、未调用其 API、未执行新实验。
+
+## 结论
+
+可以尝试。最贴合现有 A2 的用途，是把 Jev 当作“问题前提与已检索记忆之间的关系判别器”，辅助 R3a 选择具备反证资格的记忆。它也可以用于回答后的证据支持检查。当前证据支持开展独立对照实验，尚不足以支持替换已冻结的 R3a-v2.2，或宣称项目能因此消除幻觉。
+
+建议顺序：先做影子判别与人工分歧审计，再比较相同条件下的 selector，最后才考虑干预最终回答。保留记忆库、检索器、候选集合、现有主线及评价口径。
+
+## 1. Jev 的能力及需要澄清的说法
+
+Jev 是 TypeSafe 的 System One 模型，接收 state 与类型化问题，返回 Choice、Score 或 Noul；它不负责生成最终自然语言回答。Choice 适合关系分类或从既有 memory_id 中选择，Noul 适合输出一个条件成立的概率。[官方介绍](https://docs.typesafe.ai/introduction)
+
+类型受约束能避免输出不存在的类别、任意新增字段等问题，但合法类别仍可能选错。“零幻觉”不能直接解释为“不会误判反证”或“生成器回答一定正确”。官方列出的局限包括字面理解、复杂间接关系、时间比较和大段无关上下文。[官方局限](https://docs.typesafe.ai/model-jaggedness/jev-1.13)
+
+Choice/Score 的 confidence 由答案概率分布计算，不能直接当成某条证据客观正确的概率；Noul 没有同样的 confidence 字段。多个条件的概率也不能未经验证就相乘当作最终准入概率。[置信度说明](https://docs.typesafe.ai/confidence)
+
+截至本次查询，官方列出的版本是 jev-1.13.0，价格为每百万输入 token 0.042 美元，输出不计费。研究应固定版本并保存返回的模型版本、状态、问题、概率和调用成本；官网速度演示不代表本项目端到端速度。[模型与定价](https://docs.typesafe.ai/models)
+
+## 2. 与项目当前状态的对应
+
+本地关键文档实际为 README_更新版_20260617.md、research_questions_更新版_20260617.md 和 Research Roadmap_更新版_20260617.md。它们界定了“检索后、推理前”的使用资格控制，当前正式主张限定在 Memory Conflict / false-premise correction。
+
+现有 脚本/3.0/r3a_v2_selector.py 把判断拆成：
+1. 问题前提锚点匹配；
+2. 实体、槽位与值对齐；
+3. 时间 / 事件条件相容；
+4. 显式反驳，且不把“未提及”当作“否定”。
+
+Jev 可以提供这些关系的语义判断，代码继续控制最终准入、证据身份和 no-op。现有代码中的 confidence = 10 + _refutation_strength(prop) 是启发式分值，与 Jev 的分布统计量不是同一尺度，不能沿用同名字段的阈值。

+- P1 审计的 120 条候选中，118 条属于非反证或非反证但有用，未确认真反证漏触发；冻结结论为 do_not_revise_r3a_v2_2。不能因为 Jev 是新模型就把疑似候选当成漏判。
+- 78 个已触发样本的 utility 报告：R0 为 C/H/O = 34/9/35，B_triggered 为 36/8/34；correct 的配对检验 p = 0.831812。该结果没有建立显著的回答正确率提升。
+- 实验 7 的最终混合口径为 A=12、B=72、C=72、D=0、uncertain=2，共 158 个诊断案例；43 个案例有人审，其余保留机器判断。这是诊断案例的归因，不能当成全量任务分布。B 指证据存在但未呈现，C 指呈现后未使用，二者需要分别验证。

+## 3. 两个接入位置
+
+| 位置 | Jev 判断内容 | 代码负责的动作 | 优先级 |
+|---|---|---|---|
+| 检索后、回答前 | 某条记忆是否明确反驳当前前提 | 选择已有 memory_id、核对原文、按现有策略准入或 no-op | 首选试验 |
+| 回答生成后 | 回答中的具体断言是否受到给定证据支持；是否忽略明确反证 | 记录分歧；以后独立验证受控重答 | 次选试验 |
+
+第一阶段的输入只包含 question、raw_memories 及推理时本就可见的元数据。排除 gold_answer、question_type、baseline_label、distractor 标签和人工最终裁决。评价阶段可以使用冻结的 gold-only 口径和人工关系标签。
+
+逐条记忆可采用以下原子问题：
+- 是否指向同一实体与同一属性 / 活动？
+- 文本是否明确否定问题中的主张，或给出与该主张不相容的状态？
+- 该反驳是否适用于问题指定的时间与事件范围？
+
+关系选项应包含 REFUTES_PREMISE、DIRECT_SUPPORT、INSUFFICIENT_TO_DECIDE、OTHER；最终证据选择包含 NONE。时间先后、日期窗口和 ID 到原文的映射交给代码。不把未来计划等同于已发生事件，不把偏好不同等同于决策反转，不把缺少信息等同于反证。
+
+这是拟议接口，不是已验证策略；多条原子问题分别可靠，不代表组合门控已经可靠。需要评价最终准入结果。
+
+Jev 不会自动把遗漏的原文送进回答上下文，也不会保证生成器使用已送入的证据。对于实验 7 的 B 类，应检查准入证据是否完整呈现；对于 C 类，应固定相同证据呈现方式后检验回答是否改善。回答后核验需要提供实际呈现的来源，不能借助 gold 把检测包装成可部署能力。
+
+## 4. 最小对照方案
+
+### 第一阶段：影子判别，不改变现有回答
+
+优先使用约 200–300 条可独立审计的问句—记忆对，覆盖明确反证、同主题但槽位不同、时间不匹配、模糊关系和未提及。纳入规则未触发及非目标案例；分层仅用于采样和事后统计。
+
+按会话 / 用户分离开发集与测试集，避免同一批记忆同时参与阈值选择和最终评价。旧审计数据可以做开发参考，但不能一边据其改提示、一边再把同批数据当最终测试。
+
+比较现有规则、Jev、结构化输出的通用 LLM，使用相同输入和关系定义。人工盲审分歧，记录抽样方式与分层权重。核心问题是：Jev 是否识别到真实、可用且规则未识别的关系，以及是否新增误准入。
+
+### 第二阶段：固定实验条件比较最终回答
+
+| 分支 | 作用 |
+|---|---|
+| R0 | 原始回答基线 |
+| Rule-A2 | 冻结的 R3a-v2.2 |
+| Jev-A2 | 相同候选问题集合与准入呈现策略，使用 Jev 选择证据或 NONE |
+| LLM-A2 | 相同接口，使用通用 LLM 判断关系 |
+| Rule+Jev | 仅核验现有规则提出的候选，作为单独的否决策略消融 |
+
+先在相同规则 gate 的问题集合上比较 selector；按实际触发交集补做分析，区分证据选择收益与弃权 / gate 改变的收益。扩展未触发样本是另一个实验，不与 selector 对照混在一起。
+
+固定记忆库、检索结果、候选记忆、生成模型、随机设置、上下文预算、呈现模板和评价口径。无准入证据时回到既有 no-op，不强制生成器回答 Unknown。
+
+需要报告：
+- 反证准入 precision、机会 recall、覆盖率、非目标误触发；机会 recall 的分母必须经审计确认有反证，不能用可疑候选代替。
+- 整体与目标子集 C/H/O，尤其 omission→correct、omission→hallucination、correct→hallucination。
+- 证据是否完整呈现，以及呈现后是否被回答采用。
+- 最终准入概率的校准、风险与覆盖率、延迟和总调用成本。
+- 配对置信区间；Jev 不同时担任方法组件和唯一最终裁判。
+
+成功标准应预先约定：在相近反证精度下增加经确认的覆盖，或改善最终 C/H/O 且有合理的净修复收益。只有格式更稳定、调用更便宜或触发更多，不足以证明幻觉得到改善。
+
+## 5. 论文贡献与相关工作
+
+官方已有 Classifying RAG passages 示例：检索后判断相关性、可用证据、前提冲突和提示注入，并把证据与冲突信息分别送给生成器。因此，“在检索与生成之间增加 Jev gate”本身不能作为本项目的新贡献。[官方 RAG 示例](https://docs.typesafe.ai/cookbooks/classifying_rag_passages)
+
+两个直接相关的预印本：
+- [Just Ask Jev / RLCDAlignBench](https://arxiv.org/abs/2609.29429)：包含幻觉检测，并分析输入上下文、标签定义和校准问题；没有证明长期记忆中的反证准入能改善最终回答。
+- [Evaluating and Benchmarking the System One Model Jev](https://arxiv.org/abs/2609.37647)：覆盖分类与自然语言推断；显示二值概率不能机械沿用 0.5 阈值。结果不能直接移植为 HaluMem 的反证精度。
+
+由这些来源与项目证据作出的研究判断是：贡献应放在“命题条件化的记忆反证资格定义、明确的 no-op / 准入动作、呈现与使用的因果对照、误准入与遗漏的权衡”，并检验这些原则能否跨判别器成立。Jev 可作为一个实现和强对照。
+

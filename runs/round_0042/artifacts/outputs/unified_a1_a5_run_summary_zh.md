# 统一解析后 A1-A5 全量实验总结

## 实验口径

- 研究对象：MEMOS Medium + Long 中，raw memory 至少完整支撑一条 gold evidence 的 896 条 strict 样本。
- 主分析池：其中 A0 精确重放仍答错的 867 条；这里报告的是错误恢复率，不是 MEMOS 全量准确率。
- 补充分析池：完整 896 条 strict 样本，用于观察 29 条 A0-replay 正确样本是否发生回退。
- 所有 UA 条件先用与 A6 相同的 canonical parser 统一解析全部 raw memories，再施加对应 A1-A5 操作。
- 回答模型、temperature、回答 prompt 和 gold-only judge 均与原实验一致；judge 200 条复判自一致率为 97.0%。

## 条件定义

| 条件 | 操作 |
|---|---|
| A6 | 全部 raw memory 统一解析，保持原检索顺序，不加标签 |
| UA1 | A6 基础上把 oracle gold memories 排到前面 |
| UA2 | 统一解析后只保留 oracle gold memories |
| UA3 | UA2 加关系型授权标签 |
| UA4 | 保留全部统一解析记忆，只给 oracle gold memories 加关系型授权标签 |
| UA5 | UA4 基础上，再给原本为 ASSERT 的 oracle gold memories 加 VOUCH |

## 主结果：867 条 A0 稳定错误样本

| 条件 | 翻正数 | 恢复率 |
|---|---:|---:|
| A6 | 271/867 | 31.26% |
| UA1 | 278/867 | 32.06% |
| UA2 | 425/867 | 49.02% |
| UA3 | 462/867 | 53.29% |
| UA4 | 300/867 | 34.60% |
| UA5 | 339/867 | 39.10% |

最强条件是 UA3。相邻配对结果显示：单纯把 gold 排到前面没有稳定增益（UA1-A6 = +0.81pp，p=0.641）；从 gold-first 改为 gold-only 带来 +16.96pp（p<1e-17）；在 gold-only 上增加关系型授权再带来 +4.27pp（p<1e-5）。在不做过滤的全量上下文中，关系型授权 UA4 相对 A6 增加 +3.34pp（p=0.0087），UA5 相对 UA4 再增加 +4.50pp（p=0.00040）。

## 与原 A1-A5 的同池比较

下表只比较双方都覆盖的 737 条 visible-supported 样本。

| 条件 | 原解析 | 统一解析 | 差值 |
|---|---:|---:|---:|
| A1/UA1 | 11.67% | 28.49% | +16.82pp |
| A2/UA2 | 40.84% | 44.78% | +3.93pp |
| A3/UA3 | 46.13% | 49.80% | +3.66pp |
| A4/UA4 | 9.36% | 31.21% | +21.85pp |
| A5/UA5 | 23.88% | 36.09% | +12.21pp |

五组统一解析结果都显著高于对应旧条件（未校正 exact McNemar p 均小于 0.011）。提升在保留全量记忆的 UA1、UA4、UA5 上最大，说明旧 serializer 的漏失会严重削弱重排和就地标签策略；gold-only 的 UA2、UA3 本来已过滤到 gold，统一解析的额外收益较小但仍为正。

## 解析漏失层

在旧实验无法覆盖的 130 条 serialization-loss 样本上，A6/UA1/UA2/UA3/UA4/UA5 的恢复率分别为 53.08%、52.31%、73.08%、73.08%、53.85%、56.15%。UA2 与 UA3 完全相同，说明这一层的主要收益来自让 gold memory 进入上下文并去除其他记忆，而不是关系型授权。

## 完整 strict 池补充结果

在包含 29 条 A0-replay 正确样本的 896 条池中，UA3 为 480/896（53.57%）：相对 A0 翻正 462 条、退化 11 条，净增 451 条（+50.33pp）。这张表用于检测回退，不应表述为 MEMOS 1,987 条全量准确率。

## 结论边界

统一解析是必要的公共前处理，但单独统一解析或 gold-first 重排不足以解决问题。当前结果支持的最强组合是“统一解析 + oracle gold-only 过滤 + 关系型授权”。其中 gold-only 依赖 oracle gold IDs，属于机制上界而非可部署控制器；可部署版本仍需用不依赖 gold 标签的 post-retrieval admission 近似这一过滤决策。所有 p 值均为未做多重比较校正的 exact McNemar 结果。

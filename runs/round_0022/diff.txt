+# 实验协议：Oracle Admission 翻转实验（E1，Memos 全量版）
+
+> 目的：在 **Memos baseline 已经答错且样本有 gold evidence** 的集合上，测量有多少错误可以仅通过**检索后准入层干预**被矫正。
+>
+> 准入层干预只允许重排、过滤、授权标注；不改 memory store，不重跑 retriever，不加入 raw_memories 之外的新记忆，不修改生成器，不泄漏 gold answer。
+>
+> 本实验是 oracle 上界测量：允许使用 gold evidence 和 HaluMem question_type/gold 标签来构造理想准入决策；正式 A2 方法不可接触这些 oracle 信息。
+

+### 1.2 E1 全量池
+
+E1 不再抽样 200 条。直接使用 Memos 两个子集里满足以下条件的全量样本：
+
+1. `baseline_label != "correct"`；
+2. `gold_evidence` / `evidence` 非空；
+3. `raw_memories` 已保存，且来自原 baseline QA 时实际返回的 Memos 检索结果。
+
+全量池规模固定为：
+
+| run_id | 子集 | wrong + gold evidence | strict semantic supported | partial/support | strict supported rate |
+|---|---|---:|---:|---:|---:|
+| `memos_medium` | Medium | 989 | 445 | 565 | 44.99% |
+| `memos_long` | Long | 998 | 451 | 564 | 45.19% |
+| **合计** | Medium + Long | **1987** | **896** | **1129** | **45.09%** |
+
+其中：
+
+- `wrong + gold evidence` 是本实验实际运行全集，共 `989 + 998 = 1987` 条。
+- `strict semantic supported` 表示 semantic judge 认定至少一条 `raw_memories` 完整支撑至少一条 gold evidence，共 `445 + 451 = 896` 条。
+- `partial/support` 表示至少 partial 或 supported，共 `565 + 564 = 1129` 条。
+
+后续报告必须同时给出两个分母：
+
+1. **Full-pool 指标**：在全部 1987 条上计算，回答“当前 Memos 错误集合里，准入层最多能救多少”。
+2. **Retrieved-strict 指标**：只在 896 条 strict semantic supported 上计算，回答“证据已经检回但答错时，准入层能救多少”。这是 E1 的主上界指标。

+## 3. 样本选择脚本：`01_select_memos_full.py`
+
+输入：
+
+- `outputs/baseline_full/memos_medium/memos_medium_qa.jsonl`
+- `outputs/baseline_full/memos_long/memos_long_qa.jsonl`
+- `outputs/baseline_wrong_gold_semantic_audit/semantic_gold_evidence_detail.jsonl`
+
+步骤：
+
+1. 读取两个 Memos baseline QA 文件。
+2. 保留 `baseline_label != correct` 且 gold evidence 非空的样本。
+3. 按 `run_id + line_no` 合并 semantic support cache。
+4. 从 `evidence_results[*].best_memory_ids` 中构造：
+   - `gold_memory_ids`：status 为 `supported` 的 memory ids；
+   - `partial_memory_ids`：status 为 `partially_supported` 的 memory ids；
+   - `other_memory_ids`：其余 raw memory ids。
+5. 设置 `retrieval_stratum`：
+   - `strict_supported`：`gold_memory_ids` 非空；
+   - `partial_supported`：无 strict，但 `partial_memory_ids` 非空；
+   - `no_gold_retrieved`：两者都为空。
+6. 不抽样，输出全部 1987 条到 `outputs/e1_memos_full_oracle/samples_memos_full.jsonl`。
+7. 输出 `sample_pool_summary.md`，必须复核行数：
+   - `memos_medium = 989`
+   - `memos_long = 998`
+   - `total = 1987`
+   - `strict_supported total = 896`
+   - `partial/support total = 1129`
+
+如果上述计数不匹配，立即停止，不进入生成阶段。

+## 4. 实验条件（within-subject）
+
+同一样本跑全部条件。唯一变量是传给 `PROMPT_MEMOS` 的 memory context 内容、顺序或标注。
+
+| 条件 | 名称 | 上下文构造 |
+|---|---|---|
+| A0 | replay | 原始 `raw_memories`，原顺序，无标注；用于复现 baseline |
+| A1 | oracle-promote | 保留全部 `raw_memories`，把 `gold_memory_ids` 移到最前；其余记忆原相对顺序不变 |
+| A2 | oracle-filter | 仅保留 `gold_memory_ids`；若无 strict gold memory，则上下文为空并标记 `no_strict_evidence` |
+| A3 | oracle-full | A2 过滤 + 按第 5 节给保留记忆附 oracle license 标注 |
+| A4 | license-only | 原始 `raw_memories` 原顺序不过滤，仅给 `gold_memory_ids` 附 oracle license 标注 |
+
+主实验默认跑 A0-A4 全部 5 个条件。
+
+对于 `retrieval_stratum != strict_supported` 的样本：
+
+- A1 不移动任何记忆，等价于 A0 的 memory 顺序，但仍重新生成一次以保持 within-subject 结构。
+- A2/A3 使用空 memory context，不得把 gold evidence 直接塞入上下文。
+- 这些样本纳入 full-pool 指标，但不纳入 retrieved-strict 主指标。
+
+---
+
+## 5. License 标注规则（A3/A4）
+
+license 只附加在 `gold_memory_ids` 对应的检索记忆上。标注文本必须来自固定模板，严禁包含 gold answer 或 gold evidence 的改写。
+
+| 规则 | license | 固定模板 |
+|---|---|---|
+| `question_type == "Memory Conflict"` | REFUTE | `[证据说明] 该记忆与问题中的某个前提直接矛盾。你被允许且应当依据该记忆指出前提错误，而不是回答"不知道"。` |
+| `question_type == "Dynamic Update"` | SELECT | `[证据说明] 该记忆是关于此事项的最新有效状态，若与其他记忆冲突，以本条为准。` |
+| 记忆或问题含显式条件 cue，如 `if / only when / under / unless / as long as / depends on` | CONDITION | `[证据说明] 该记忆仅在其所述条件下成立，回答时必须显式说明该条件。` |
+| 其余 question_type | ASSERT | 不加标注，等同裸记忆 |
+
+映射函数必须显式实现为：
+
+```python
+def label_to_license(question_type: str, sample: dict, memory: dict) -> str:
+    ...
+```
+
+规则不确定时落到 `ASSERT`，并在 `run_config.yaml` 与 `results_summary.md` 中记录 license 分布。
+
+---
+
+## 6. 泄漏与合规自检
+
+每次构造 A3/A4 context 后必须执行自检：
+
+1. license 标注文本必须完全等于第 5 节固定模板之一。
+2. license 标注文本中不得出现 `gold_answer` 字符串。
+3. license 标注文本中不得出现任一 gold evidence 的连续 8 个以上 token。
+4. `gold_answer` 或 gold evidence 出现在原始 memory 文本中允许，因为那是 baseline 已检索内容；但不得出现在新增标注文本中。
+5. 不调用 Memos search，不修改 Memos memory store，不删除、不更新、不追加任何 memory。
+
+自检失败则该样本该条件不得生成，写入 `leakage_failures.jsonl` 并停止整轮。

+## 8. 指标与统计脚本：`04_analyze_memos_full.py`
+
+先定义：
+
+```text
+stable_wrong = A0 replay 判定仍为 non-correct 的样本
+retrieved_strict = stable_wrong ∩ retrieval_stratum == strict_supported
+full_pool = stable_wrong 的全部样本
+```
+
+必须报告 A0 复现率：
+
+```text
+A0_replay_noncorrect_rate = |stable_wrong| / 1987
+```
+
+若 A0 replay non-correct rate < 85%，所有翻转率必须标注“replay unstable”。
+
+### 8.1 主指标
+
+对每个条件 X ∈ {A1, A2, A3, A4} 同时报告：
+
+```text
+flip_rate_full_pool(X) = P(judge_label_X == correct | full_pool)
+flip_rate_retrieved_strict(X) = P(judge_label_X == correct | retrieved_strict)
+```
+
+`flip_rate_retrieved_strict(A3)` 是 E1 的主上界指标。
+
+### 8.2 转移矩阵
+
+在 full_pool 与 retrieved_strict 两个分母下分别报告：
+
+```text
+baseline/A0 的 {hallucination, omission}
+    -> X 的 {correct, hallucination, omission}
+```
+
+重点单列：
+
+- `H -> C`：理想纠错；
+- `H -> O`：从幻觉变沉默，次优；
+- `O -> H`：恶化，必须标红；
+- `C_after_A0_replay -> non-C`：replay 波动，不计入 stable-wrong 主指标但要报告。
+
+### 8.3 配对检验与增益分解
+
+报告 McNemar 检验：
+
+- A3 vs A1：授权 + 过滤 + 位置 是否显著优于纯位置；
+- A3 vs A2：license 授权增量；
+- A4 vs A0：纯授权效应。
+
+输出瀑布图数据：
+
+```text
+flip(A1)                 # 位置效应
+flip(A2) - flip(A1)      # 过滤增量
+flip(A3) - flip(A2)      # 授权增量
+flip(A4) - flip(A0)      # 纯授权效应
+```
+
+### 8.4 分层报告
+
+至少按以下字段分层：
+
+- dataset：medium / long
+- question_type
+- retrieval_stratum：strict_supported / partial_supported / no_gold_retrieved
+- baseline_label：hallucination / omission
+- semantic_any_contradicted：true / false

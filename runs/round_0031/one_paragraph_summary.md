Memos 的 `raw_memories` 是检索 API 返回的完整结构化结果，而 `context_str_full` 才是真正放进回答 prompt、被 LLM 看到的文本；由于 baseline 的格式化函数不会把只有 `preference` 和 `reasoning` 字段的偏好记忆写入 context，896 条在 raw 层被判定为至少检回一条 gold evidence 的样本中，实际只有 763 条的支撑记忆对回答模型可见，另有 133 条虽然检索器返回了证据，但证据在检索结果转成 prompt 时被遗漏。因此，896 条适合衡量检索召回率，研究“LLM 已看到证据却没有使用”的 usage gap 时应使用 763 条，而 133 条应单独归为检索后序列化或准入丢失；同时，baseline 重放必须直接复用 `context_str_full`，不能从 `raw_memories` 重新拼接，否则会给模型加入原本没看到的记忆，使实验不再是严格复现。
